# Roadmap

## MVP

- 首页
- 前台文章列表
- 前台文章详情
- 前台项目展示
- 前台音乐卡片
- 后台登录
- 后台文章创建、编辑、删除
- 后台项目创建、编辑、删除
- 后台音乐创建、编辑、删除
- Markdown 内容渲染
- MySQL 持久化
- Redis 保存后台登录 token

## 下一阶段

- 分类与标签管理
- 评论系统
- 文章搜索
- 访问统计面板
- 前台主题切换
- 后台密码加密与用户表
- Redis 热门文章缓存
- 深海开场动画
- 页面切换动画

## 风格方向

- 整体气质偏冷色、深海、下沉、玻璃感、电子 UI。
- 视觉语言可以致敬 Persona 3 Reload 的蓝色仪式感和切换节奏，但不直接使用官方素材。
- 首页开场后续做成原创的“人物坠入海底”动画，再逐步和细节设定对齐。
